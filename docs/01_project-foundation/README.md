# Project Foundation

The Project Foundation defines why the Microgreens ERP project exists, how it thinks and how its long-term responsibilities are governed.

It connects the project's origin, philosophy and values with the strategies that guide biological production, engineering, research, technology and human responsibility.

These documents establish direction and boundaries.

Technical implementation is documented elsewhere in the repository.

## Purpose

The Project Foundation defines:

- why the project exists;
- which future it seeks to support;
- how decisions should be approached;
- which values and ethical boundaries apply;
- how major systems should develop;
- how knowledge, risk and responsibility are preserved;
- how the project may continue beyond its current stage.

The documents should be read as one connected foundation rather than as isolated statements.

## Scope

The Project Foundation establishes strategic direction.

It does not replace:

- engineering documentation;
- biological production procedures;
- food-safety systems;
- software architecture;
- operational instructions;
- research protocols;
- legal or regulatory requirements.

Those documents explain implementation within the boundaries established here.

## Authority and Change

Project Foundation documents guide lower-level strategic, technical and operational decisions.

When documents appear to conflict, interpretation should begin with:

1. Vision;
2. Mission;
3. Core Values;
4. Ethics;
5. Stewardship and Governance.

The foundation may evolve as evidence, responsibilities and circumstances change.

Material changes should follow documented review and preserve their reasoning through version control and Decision Records.

Change should clarify or strengthen the project rather than quietly replace its purpose.
